# Portfolio

Anton's personal portfolio site: projects, life, resume and contact.

## Projects

**Project**:
A piece of work shown as a card on the home and projects pages.
_Avoid_: Showcase, work item

**Case study**:
An in-depth write-up page for a single project. Visitors reach it through "Read more".
_Avoid_: Detail page, project page

**Live link**:
The URL of a project's deployed site, app or store listing.
_Avoid_: Website, product, prod, demo

**Source link**:
The URL of a project's code repository.
_Avoid_: Repo link
